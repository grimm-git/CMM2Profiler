Increment

Increments and decrements are used quite often in programs. MMBasic supports two methods of doing them:

  • The classic method with a = a + b or
  • using the INC command

MMBasic supports only the INCrement command and simulates the DECrement command with negative increments. see table below.

Performance Potential

The following data have been measured on an Color Maximite 2 G2 (480MHz) with MMBasic 5.07.01.

Test conditions: Each statement has been measured 100000 times and the average time was taken. This was then set as base to measure the performance gain of the replacement statement. This was necessary, because each statement needs a different time and the performance gain in percent should be accurate.

Positive increments should always be done with the INC command. They are significant faster or at least equal.

Negative increments are only more performant with small numbers. Parsing the extra negative sign consumes all the benefits from the faster command.
